## Delivered behavior and interfaces

- `bridge-core::{model,error,event,config}` exports the exact P05 contract names,
  UUID aliases, discovery/update/command records, HAP identity data, events and
  the Tokio oneshot `CommandEnvelope`. No adapter or Store is implemented.
- Commands validate generic position/brightness/tilt ranges, declared capability,
  current ownership/availability and optional manufacturer bounds/steps. Numeric
  step arithmetic widens before subtraction to avoid overflow at i64 extremes.
- `legacy` and `observe` reject commands with `not_native`; both deny publication.
  Momentary garage actions do not imply deterministic open/close capabilities.
- Unknown samples require no value/timestamp; other qualities require a value,
  and confirmed samples require an observation timestamp. State-key validation
  checks scalar type, generic bounds and the five declared door states. No
  validation mutates a sample, upgrades an estimate or simulates physical feedback.
- All twelve errors provide stable codes and constant secret-free public messages.
- TaHoma configuration uses the `mode` tag, rejects mixed/unknown fields, and has
  explicit local-token or Somfy-Europe account configuration with file paths.
  Private gateway selections have no Debug/Serialize implementation. No secret
  file is opened. Provider declaration is not proof of cloud authentication support.
- HomeKit configuration only carries `stop_and_review`; no selectable/approved
  backend or executable transport is added.
- `fixtures/core/{contracts,config}.json` contains entirely fictional shared examples.
  They test internal type representations and are not public API DTOs.

Affected files: four core modules, `lib.rs`, core contract tests, root/core
manifests and lockfile, two fictional JSON fixtures, contracts, dependency/license
inventory, P04 ADR exception, evidenced P05 checkboxes, current state and this report.
No active CLI/integration/transport caller uses these new types. Future
P06/P07/P11/P18/P20 consumers must enforce the documented semantic validation,
redaction and ownership boundaries; physical provenance cannot be inferred by a
data type. Public struct fields and deserialization alone do not guarantee validity.
Serde internally tagged unit commands ignore extra JSON keys; parameterized
commands and TaHoma config reject unknown fields. Ignored keys cannot select
manufacturer operations or URLs. A stricter outer API policy belongs to P08.
