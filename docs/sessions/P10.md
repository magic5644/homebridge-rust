## Behavior and boundaries

- Browse only `_kizboxdev._tcp.local.`. Accept a syntactically valid numeric
  `gateway_pin` TXT value, never infer identity from host or display names.
- Derive canonical TLS DNS `gateway-{pin}.local` from TXT, following the official
  OpenAPI server template; preserve the advertised service port and separate
  optional resolved IP. This is an untrusted discovery candidate, not TLS proof.
- The API discovers all candidates: the caller must compare the selected
  `expected_pin` with its configured PIN before connecting. A matching display
  name with a different TXT PIN never matches that selection. P11 must validate
  the manufacturer CA, DNS identity and actual gateway identity.
- Use neutral candidate integration ID `tahoma-main`. Before registering or
  persisting a candidate, bind the configured integration ID. Deriving a public
  integration ID from a private gateway PIN would leak household identity.
- Deduplicate by TXT PIN, choose a deterministic usable IP, reject conflicting
  advertised ports, cap results at 64 (`Busy`), and reject durations above 60
  seconds (`Validation`). Zero timeout returns without starting mDNS.
- Completion, source errors and cancellation run cleanup exactly once. The real
  daemon receives its shutdown request and its acknowledgement is awaited for
  at most one second synchronously, including when the future is dropped.
  A failed or unacknowledged ordinary cleanup returns `Unavailable`; cancellation
  has no result channel. No background discovery task is spawned by this adapter.
- Ignore unusable IPs and do not discard IPv6 link-local scope into `IpAddr`:
  retain canonical DNS with no resolved-IP override instead.
- Existing `TahomaConfig::LocalToken` supports a manual `resolved_ip` override
  while preserving the independent TLS DNS name. No extra config schema or
  manual-address abstraction was added.
- No current runtime caller exists. P11 can use this discovery API after P07 and
  other prerequisites are integrated; no HTTP client is implemented here.
